# J2534 / Pass-Thru (lab)

Analysis-only support for **SAE J2534** Pass-Thru discovery and a minimal library probe.  
**Not** a replacement for OEM flash tools (ISTA, Xentry, Techstream, FDRS, …).

## Safety boundary

| Allowed | Forbidden |
|---------|-----------|
| Registry discovery (no DLL load) | `PassThruWriteMsgs` (programming / flash) |
| `PassThruOpen` | Security access / seed-key |
| `PassThruReadVersion` | Programming IOCTLs |
| `PassThruClose` | Channel connect for vehicle control |
| Status / self-diagnostic report | Actuator / periodic control messages |

Product posture remains: **analysis aid only** — no ASIL confirmation, no eCall, no OTA install.

## Commands

| Command | Purpose |
|---------|---------|
| **J2534: Discover Drivers (registry)** | Enumerate `PassThruSupport.04.04` / `05.00` (HKLM/HKCU + WOW6432Node). Windows only. |
| **J2534: Probe Library (analysis-only)** | Load `libraryPath` → Open / ReadVersion / Close. Modal confirm. |
| **J2534 Pass-Thru Status (stub)** | Lab stub + configured path + next steps. |
| **D-PDU Status** | ISO 22900 stub (architecture alignment). |

## Settings

```
vehicleDebug.j2534.libraryPath     # Path to vendor FunctionLibrary DLL
vehicleDebug.j2534.pythonPath32    # Optional 32-bit Python for OEM DLLs
```

Most classic OEM J2534 DLLs are **32-bit**. Prefer a 32-bit Python interpreter via `pythonPath32` when probing; 64-bit Python often fails to `LoadLibrary`.

## Platform notes

| OS | Discovery | Probe |
|----|-----------|--------|
| **Windows** | Registry scan | DLL load (analysis-only API subset) |
| **Linux / macOS** | `unsupported_os` | Prefer SocketCAN, PEAK, Vector, DoIP |

SAE **J2534-5** describes alternate platforms; real non-Windows support remains vendor-specific.

## Self diagnostic

**Run Self Diagnostic** includes:

- Backend presence of `j2534_probe.py`
- Deep probe: registry discover → `ok` + driver count (Windows) or `skip` (other OS)

## Typical lab flow (Windows)

1. Install a vendor Pass-Thru driver (Mongoose, OpenPort, OEM VCI, …).
2. Palette → **J2534: Discover Drivers (registry)**.
3. Optionally set `libraryPath` from the prompt.
4. Optionally set `j2534.pythonPath32`.
5. Palette → **J2534: Probe Library (analysis-only)** → confirm.
6. Review JSON (API / DLL / firmware versions).
